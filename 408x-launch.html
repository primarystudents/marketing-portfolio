01

背景与营销目标

先明确甲方委托的任务边界与要达成的结果

甲方给定

项目背景

408X 是标致品牌焕新背景下推出的全新无界座驾，官方定位"新法式无界座驾"，落在 14.57–17.97 万元这一竞争最密集的价格带。该区间同时被同级合资运动轿跑与自主车型占据，用户注意力与决策路径已高度内容化。

委托内容
  • 甲方委托乙方承接 408X 上市整合传播。
  • 核心节点为上海国际车展上市，并延续至试驾传播。
  • 形式覆盖车展集中传播、平台专访、KOL 打卡、区域试驾。
执行节奏
  • 上海车展正式上市 → 试驾传播（贯穿整个上市周期）。
  • 上市窗口有限，认知必须在窗口内建立、放大并推进到体验。

营销目标（分层设定）

目标层我们要达成的结果判断标准
认知层让目标人群建立"无界"的差异化认知，而非只记住参数品牌与车型搜索、相关讨论量提升
声量层在车展等关键节点形成集中传播峰值，带动持续讨论见刊量、平台推荐、声量峰值
体验层把"看到"推进到"想试"，为到店与试驾蓄水试驾预约、有效线索
营销任务（结论）

在上市窗口内，围绕"无界"建立差异化认知，在车展节点集中引爆声量，并把认知推进到试驾与到店——完成"认知建立 → 声量引爆 → 体验深化"的完整覆盖。

02

品牌理念与产品理解

承接执行的前提，是先把品牌和产品讲清楚

品牌既有

品牌理念

标致品牌以法式设计美学与运动基因为底色，408X 是其品牌焕新之作，核心主张是"无界"——打破车型类别与生活方式之间的边界。

设计美学

法式设计语言与狮魂美学，是品牌最直观的记忆点，也是视觉类内容与车展传播的基础。

运动基因

赛道与底盘调校积淀，支撑"好开、有驾驶乐趣"的产品印象，是试驾内容的信任来源。

无界主张

"生而无界"的态度主张，与目标人群的自我表达诉求高度契合。

产品理解：三层价值结构

层级内容408X 对应
产品事实产品客观具备的特征中型无界掀背车身、Fastback 溜背造型（14° 倾角 / 0.27Cd）、CLDR 运动底盘、1.6T + 8AT 动力总成、i-Cockpit 座舱
用户价值这些特征为用户带来什么一车多能、个性辨识度、驾驶乐趣与操控信心
传播主张希望受众最终记住的那句话以"无界"为核心，贯穿全部内容
为什么执行环节要先理解这些
  • 稿件审核与改稿需要判断"什么该说、怎么说"：口径是否与品牌一致、卖点是否有产品支撑、表达是否合规。
  • 竞品分析需要先知道"我们比谁强、强在哪"，才能把差异化落到对比稿与达人内容里。

竞品对标分析与营销方向

投放之前：对标差异，落到既定的营销方向与宣传打法

竞品研究的任务

品牌方在任务书中已给定营销方向——以"无界"为核心（产品定位"新法式无界座驾"、主题"生而无界"、用户价值"无界 Life"），因此本节不重复论证方向，而是解决执行问题：宣传什么、怎么宣传、放在什么节奏。分析顺序为：圈定竞品 → 选定对标车型 → 拆解其定位与打法 → 把既定方向落成可执行的宣传点与打法，作为第 04–07 节的输入。

第一步 · 竞争格局与我方宣传切入点

竞争类型代表车型竞品打法我方宣传切入点依据

第二步 · 对标车型的选定

圈定候选竞品池（公开对比平台常见）

大众凌渡 L、大众 CC、本田英仕派、福特蒙迪欧、马自达阿特兹 等。

选定核心对标车型：大众凌渡 L

按价格带、车身形态、目标人群、传播抓手四个维度筛选，凌渡 L 与 408X 重合度最高——价格带高度重叠、人群同为追求个性的年轻用户、且同样以"轿跑 / 无界"作为传播抓手。因此选定凌渡 L 作为核心对标车型，作为下一步确定宣传打法的直接参照。

目标人群与核心洞察

人群画像

官方目标人群为 Z 世代，核心为 25–35 岁、集中在一二线及新一线城市、注重个性表达与审美的消费群体；反感被单一标签定义，购车决策前会大量对比，并高度依赖体验类内容。

三条核心洞察

洞察一 · 车是自我表达

他们要的不是一张参数清单，而是"这辆车代表我是谁"。传播必须提供身份认同，而不是功能罗列。

洞察二 · 好奇需要场景

他们对"无界"有天然好奇，但需要具体使用场景来支撑理解——必须把"一车多能"讲成看得见的生活方式。

洞察三 · 对比与体验定决策

决策前会反复对比、看体验内容。因此对比稿建立位置、试驾内容促成决定，是决策链上的关键触点。

04

核心传播策略

用一条主张贯穿，用三步递进完成从认知到体验

团队确认

核心创意主张

主张（品牌方给定，详见第 03 节）

"生而无界"

本节重点不是主张本身，而是如何把它执行出去——用哪几步、分哪几个打法、落到哪些内容与节点。

策略主线：三步递进

STEP 01
用设计抢注意
以车展现场与视觉类内容，第一时间建立"狮魂美学 + 法式设计"的辨识度，解决"看不见"的问题。
STEP 02
用对比定位置
以对比稿把"更大 / 更强 / 更值"讲清楚，解决"和谁比、值不值"的决策问题。
STEP 03
用体验促转化
以试驾体验内容把兴趣推进到到店，解决"想不想试"的临门一脚。

三个核心打法

打法一 · 集中引爆

把车展作为唯一声量峰值节点，媒体、达人、内容集中释放，用一次峰值带动持续讨论，而不是全程平均投放。

打法二 · 分层说服

不同内容各承担一个说服任务，避免同质化曝光（内容与角色的分工见第 05 节）。

打法三 · 体验承接

所有内容指向试驾预约，形成"看内容 → 做对比 → 去试驾"的闭环，避免传播停在曝光层。

内容矩阵：六类内容的分工

内容类型承担的角色核心信息
主通稿建立定位认知、统一传播口径无界定位 + 上市核心信息
专题稿单点深化（设计 / 驾控）设计美学或运动驾控
深度对比稿解决"和谁比、值不值"的决策问题对标凌渡 L 的差异化优势
专访 / 高层对话品牌与战略背书品牌愿景与产品战略
KOL / 达人内容圈层渗透、口碑扩散以创作者特色承载同一主张
试驾体验内容体验深化、转化前置真实驾驶感受与操控
互补原则

各类内容围绕同一主张，但角度不重复：通稿讲"是什么"，专题稿讲"好在哪"，对比稿讲"为什么选我"，专访讲"谁在做"，达人内容讲"我怎么用"，试驾讲"开起来如何"。以此避免同质化曝光，让不同渠道各自承担不同的说服任务。
